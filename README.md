# Terminal Library System - Omay and Pagon

## Description
A Terminal-Based Library Management System in Python with user registration, secure login, book inventory, borrower management, and borrowing history. The system uses file handling to store data in .txt files.

## Authors
- Omay
- Pagon

## Features
- User Registration (Admin / Staff)
- Secure Login with SHA-256 Password Hashing
- View Books
- Add New Book
- Register Borrower
- View Borrowers
- Borrow a Book
- View Borrowing History
- Role-Based Access - Only Admin can register users
- Data saved in .txt files

## Requirements
- Python 3.8 or higher
- No external libraries needed

## Installation / How to Run
1. Download or clone this repository
2. Open terminal in the project folder
3. Run:
   python main.py
4. Login using:
   Username: admin
   Password: password

## File Handling
- users.txt - stores registered users
- books.txt - stores book records
- borrowers.txt - stores borrower records
- borrowing_history.txt - stores borrowing transactions
